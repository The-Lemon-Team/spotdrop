ПРАВИЛО ОРГАНИЗАЦИИ И СТРУКТУРЫ ПРОФИЛЕЙ В ПАПКЕ DEFAULTS
==============================================================
Проект: Bandita Player (Android Native & Web)

1. НАЗНАЧЕНИЕ ПАПКИ DEFAULTS
--------------------------------------------------------------
Папка "defaults" служит центральным хранилищем предустановленных профилей 
и коллекций музыки для Bandita Player.
В перспективе через данную директорию можно добавлять несколько профилей
(жанровые подборки, коллекции по настроению, библиотеки разных пользователей).


2. СТРУКТУРА ПАПКИ DEFAULTS
--------------------------------------------------------------
defaults/
|-- RULE.md                     (Документ-правило в формате Markdown)
|-- RULE.txt                    (Настоящий текстовый документ)
|-- default/                    (Дефолтный профиль)
|   |-- profile.json            (Метаданные профиля)
|   |-- YourLibrary.json        (ОПЦИОНАЛЬНО: Сохраненные треки из Spotify)
|   `-- Playlist1.json          (ОПЦИОНАЛЬНО: Плейлисты из Spotify)
|-- template/                   (Шаблон для создания нового профиля)
|   |-- profile.json            (Шаблон метаданных)
|   |-- YourLibrary.example.json(Пример структуры сохраненных треков)
|   `-- Playlist1.example.json  (Пример структуры плейлистов)
`-- <имя_профиля>/              (Новые профили, создаваемые по правилу)
    |-- profile.json
    |-- YourLibrary.json        (Опционально)
    `-- Playlist1.json          (Опционально)


3. ПРАВИЛА СОЗДАНИЯ ПАПКИ ПРОФИЛЯ
--------------------------------------------------------------
3.1. ИМЯ ПАПКИ
- Имя папки профиля должно быть в нижнем регистре (slug format).
- Допустимые символы: латинские буквы a-z, цифры 0-9, дефис (-) и подчеркивание (_).
- Примеры: default, rock_classics, chill_vibes, gym_workout.

3.2. СОСТАВ И ОПЦИОНАЛЬНОСТЬ ФАЙЛОВ
- profile.json: Метаданные профиля (рекомендуется).
- YourLibrary.json: Экспорт сохраненных треков Spotify (ОПЦИОНАЛЬНО).
- Playlist1.json: Экспорт плейлистов Spotify (ОПЦИОНАЛЬНО).

Файлы Spotify являются строго опциональными!
Профиль валиден даже если:
а) Присутствует только profile.json (пустой профиль для ручного добавления через интерфейс);
б) Присутствует только YourLibrary.json (только треки);
в) Присутствует только Playlist1.json (только плейлисты);
г) Присутствуют оба файла.


4. СПЕЦИФИКАЦИЯ ФАЙЛА profile.json
--------------------------------------------------------------
Формат JSON:
{
  "id": "profile_unique_id",
  "name": "Название Профиля",
  "avatarEmoji": "🎧",
  "description": "Краткое описание коллекции",
  "isDefault": false,
  "themeColor": "#00E5FF"
}

Поля:
- id (строка, обязательно): Уникальный ID профиля, например: "profile_rock".
- name (строка, обязательно): Название профиля для отображения в UI.
- avatarEmoji (строка, опционально): Символ эмодзи для аватара (по умолчанию: 🎧).
- description (строка, опционально): Описание коллекции.
- isDefault (булево, опционально): true для профиля по умолчанию, иначе false.
- themeColor (строка, опционально): HEX-цвет темы.


5. СПЕЦИФИКАЦИЯ ФАЙЛОВ SPOTIFY
--------------------------------------------------------------
5.1. YourLibrary.json (Saved Tracks / Liked Songs)
{
  "tracks": [
    {
      "artist": "Artist Name",
      "album": "Album Name",
      "track": "Track Title",
      "uri": "spotify:track:..."
    }
  ]
}

5.2. Playlist1.json (Playlists)
{
  "playlists": [
    {
      "name": "Playlist Name",
      "lastModifiedDate": "YYYY-MM-DD",
      "items": [
        {
          "track": {
            "trackName": "Track Title",
            "artistName": "Artist Name",
            "albumName": "Album Name",
            "trackUri": "spotify:track:..."
          },
          "addedDate": "YYYY-MM-DD"
        }
      ]
    }
  ]
}


6. ИНСТРУКЦИЯ ПО ДОБАВЛЕНИЮ НОВОГО ПРОФИЛЯ
--------------------------------------------------------------
Шаг 1: Создайте папку внутри defaults/, например defaults/lofi_study/
Шаг 2: Скопируйте profile.json из defaults/template/ и отредактируйте название и emoji.
Шаг 3: При необходимости поместите файлы YourLibrary.json и/или Playlist1.json в папку.
Шаг 4: Запустите плеер - новый профиль будет доступен в списке профилей.
