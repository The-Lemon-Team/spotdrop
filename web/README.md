# 🎵 Bandita Player Web: Продакшн версия с Tailscale и доступом по токену

Современный автономный веб-плеер на **React 19**, **TypeScript**, **Tailwind CSS** и **Dexie.js (IndexedDB)**. Превращает ваш экспорт из Spotify (`YourLibrary.json` / `Playlist1.json`) в бесплатный стриминговый плеер с воспроизведением из YouTube.

Работает с **100% приватностью**: без облачных баз данных и без регистрации. База данных хранится локально в браузере.

## 📱 Как запустить и слушать на смартфоне (iOS / Android)

1. **Запустите сервер на компьютере:**
   - В корне проекта дважды кликните `start-production.bat`  
     *(или выполните в PowerShell: `.\start-production.ps1`)*  
   - Либо вручную из папки `web`:
     ```bash
     cd web
     npm run build
     npm run start
     ```
2. **Включите Tailscale на телефоне:**
   - Убедитесь, что приложение **Tailscale** запущено и активно на вашем мобильном устройстве (в той же сети tailnet).
3. **Откройте ссылку в браузере телефона:**
   - Перейдите по ссылке `http://100.82.53.11:3001/?token=bandita_mobile_7f8e12d4a93c` (можно отправить её себе в Telegram / WhatsApp).
   - Авторизация произойдет автоматически, токен сохранится в cookies и `localStorage`, а адресная строка станет чистой.
   - Либо просто откройте `http://100.82.53.11:3001` и вставьте токен на экране входа.
4. **Установите как веб-приложение (PWA):**
   - **iOS Safari:** нажмите «Поделиться» $\rightarrow$ «На экран "Домой"».
   - **Android Chrome:** нажмите «⋮» $\rightarrow$ «Установить приложение» или «Добавить на главный экран».
   - Плеер будет работать во весь экран без рамок браузера, с поддержкой управления с экрана блокировки и гарнитуры (**MediaSession API**).

## ⚙️ Защита API и стриминга

Все важные серверные эндпоинты защищены проверкой токена:
- `GET /api/search` — поиск треков на YouTube (InnerTube API через прокси)
- `GET /api/stream` — потоковая передача аудио (`audio/webm`, HTTP 206 Partial Content)
- `GET /api/auth/verify` — валидация токена и автоматическая установка Cookie
- `GET /api/network-info` — статус сети и Tailscale IP
- `GET /defaults/*` — чтение предзагруженных файлов Spotify

Для смены токена отредактируйте переменную `BANDITA_AUTH_TOKEN` в файле `web/.env` и перезапустите сервер.
